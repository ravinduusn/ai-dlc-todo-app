# Personas

## P1: Solo Developer-Learner

**Name**: Alex (the developer-learner)

**Role**: Solo developer building a to-do list app for personal use and
learning web development.

**Goals**:
- Track personal tasks in a simple, distraction-free interface
- Learn web development fundamentals (HTML, CSS, JavaScript, localStorage)
- Build a working app end-to-end without framework overhead

**Pain Points**:
- Existing to-do apps are overly complex with features they don't need
- Informal methods (sticky notes, mental notes) are unreliable
- Wants to understand how things work at the browser level, not abstracted
  behind a framework

**Context**:
- Technical user comfortable with code and browser dev tools
- Uses a modern evergreen browser (Chrome, Firefox, Safari, or Edge)
- Works on both desktop and mobile screens
- Values simplicity and minimal UI over feature richness
- No need for accounts, collaboration, or cloud sync

**Priority**: Primary (and only) persona for v1.

## Persona Relationships

None — this is a single-persona application. No secondary personas are
defined for v1. The app is designed by and for this one user type.
